# 노면온도 MLP v1-v2 비교

두 모델은 동일한 미학습 2025년 12월 724시간을 테스트로 사용했다. v2의 피처와 시간 정렬은 개발·보정 기간을 기준으로 설계했으며 테스트 정답은 학습, 조기종료, 확률 보정에 사용하지 않았다.

| 항목 | v1 | v2 | 변화 |
|---|---:|---:|---:|
| RMSE | 1.212°C | 1.064°C | 12.2% 감소 |
| MAE | 0.949°C | 0.804°C | 15.2% 감소 |
| R² | 0.929 | 0.946 | 0.017 증가 |
| 지속 기준 대비 RMSE skill | 55.9% | 61.2% | 5.3%p 증가 |
| -3~+3°C RMSE | 1.015°C | 0.846°C | 16.7% 감소 |
| PR-AUC | 0.968 | 0.976 | 0.008 증가 |
| ROC-AUC | 0.988 | 0.991 | 0.003 증가 |
| Brier score | 0.0400 | 0.0433 | 0.0033 증가 |

## 변경점

1. 00:00~00:59 평균을 01:00 시점의 과거 한 시간 관측으로 표시해 최대 59분의 미래 정보가 입력에 섞일 가능성을 제거했다.
2. 현재 노면온도 외에 1·2·3·6시간 lag를 추가했다.
3. 3·6시간 이동평균과 1·3시간 변화율을 추가했다.
4. 모든 시계열 피처는 시간이 연속된 경우에만 계산하고 중간 관측이 끊긴 구간은 결측 처리했다.

v2는 더 엄격한 인과 조건에서도 회귀 오차와 동결 순위 지표가 개선됐다. 다만 0.5 고정 임계값에서 Precision은 높아지고 Recall은 낮아졌으며, 강남 전체 도로별 결빙 정확도가 아니라 원지(도) 단일 관측소의 시간 홀드아웃 결과다.
